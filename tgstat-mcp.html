Развёртывание TGStat-MCP на Railway

tgstat-mcp-http · v1.0 · 10.09.2026 · Курс «ИИ-инструменты для региональной редакции»

Что мы делаем и зачем

Разворачиваем собственный MCP-сервер для TGStat на платформе Railway.

TGStat — сервис аналитики Telegram-каналов: подписчики, охваты, ERR, упоминания, поиск по каналам и постам, тренды ключевых слов.

После развёртывания ваш ИИ-клиент (LobeHub, Cherry Studio, DeepChat) получит доступ к аналитике 20 инструментами.

Важно: это проще, чем Telegram-MCP. Не нужно получать api_id, api_hash и session string. Нужен только один ключ — TGSTAT_TOKEN. Деплоим напрямую из репозитория тренера — без Fork.

Что понадобится

  • Аккаунт на GitHub (если уже создавали для Telegram-MCP — используйте тот же)
  • TGStat-токен (api.tgstat.ru) — подробнее в Шаге 1
  • Аккаунт на Railway (бесплатного тарифа достаточно)

Шаг 1. Получить TGSTAT_TOKEN

TGStat — платный сервис аналитики. Токен привязан к вашей подписке.

  1. Зайдите на tgstat.ru и зарегистрируйтесь (или войдите, если есть аккаунт)
  2. Перейдите в раздел «API» или на api.tgstat.ru
  3. Создайте API-токен (кнопка «Создать токен» или «Get token»)
  4. Выберите нужные пакеты доступа: Search API (поиск каналов и постов) и Stat API (статистика, подписчики, охваты, ERR). Для сценариев курса нужны оба пакета
  5. Скопируйте токен — это длинная строка букв и цифр
Внимание: токен привязан к вашему аккаунту TGStat. Никому его не передавайте. Если подписка истечёт — сервер перестанет отвечать, пока вы не продлите.

Шаг 2. Создать аккаунт на GitHub (если ещё нет)

GitHub нужен для авторизации на Railway.

  1. github.com → Sign up → введите email, пароль, username
  2. Подтвердите email кодом из письма
  3. Пройдите опрос (можно Skip personalization)

Шаг 3. Развернуть на Railway

Railway запустит сервер из репозитория тренера. Вы добавляете только свой токен.

  1. Зайдите на railway.com → Login with GitHub (разрешите доступ)
  2. Нажмите New Project → Deploy from GitHub repo
  3. В поле «GitHub repo» введите: mrvolkomorov/tgstat-mcp-http
  4. Railway откроет проект. Перейдите во вкладку Variables
  5. Нажмите New Variable: TGSTAT_TOKEN = ваш токен из Шага 1
  6. Railway автоматически начнёт деплой (1–2 минуты). Дождитесь зелёного статуса
  7. Перейдите: Settings → Networking → Generate Domain
  8. Появится адрес вида https://tgstat-mcp-http-production.up.railway.app — скопируйте его

Проверка работоспособности

Откройте в браузере: https://tgstat-mcp-http-production.up.railway.app/health

Должно отобразиться: {"status": "ok", "version": "v3"}

Если ошибка 503 — подождите 1 минуту и обновите страницу.

Подключение к ИИ-клиенту

Поддерживаются: LobeHub, Cherry Studio, DeepChat.

  1. Откройте настройки MCP-серверов в вашем ИИ-клиенте
  2. Добавьте новый сервер: Name = TGStat MCP, Type = HTTP (Streamable HTTP), URL = https://ваш-домен/mcp
  3. Сохраните и включите сервер

В чате с ИИ теперь доступны 20 инструментов TGStat.

Типичные проблемы и решения

ПроблемаРешение
Ошибка 401 при /healthПроверьте TGSTAT_TOKEN (не опечатались?)
Ошибка 503Сервер запускается — подождите 1–2 мин
Модель не видит инструментыПроверьте URL (должен заканчиваться на /mcp)
Инструменты возвращают пустотуПроверьте подписку TGStat (не истекла?)

Безопасность

  • TGSTAT_TOKEN — ключ к вашему аккаунту TGStat. Никому не передавайте
  • На Railway переменные зашифрованы и не отображаются в логах
  • Если заподозрили утечку — зайдите в TGStat → API → отзовите старый токен и создайте новый
  • Не публикуйте домен Railway в открытых чатах (хотя без токена он бесполезен)

Какой ключ использовать

На занятии используем ключ тренера — он выдаётся в начале сессии.

Дома, для домашнего задания и собственных сценариев, каждый участник получает СОБСТВЕННЫЙ ключ на OpenRouter или AiTunnel.

OpenRouter — получение ключа

  1. Зайдите на openrouter.ai → Sign In (через Google/GitHub)
  2. Профиль → Settings (шестерёнка) → Keys
  3. Create Key → имя (например n8n-track-A) → Create
  4. Скопируйте ключ (начинается на sk-or-...) — сохраните надёжно
Важно: ключ показывается один раз. Потеряете — создайте новый.

AiTunnel — получение ключа

  1. Зайдите на aitunnel.ru → Регистрация
  2. Email + телефон → подтверждение SMS
  3. Профиль → API-ключи → Создать ключ
  4. Имя (например n8n-domashka) → скопировать ключ
  5. Пополнение: Профиль → Пополнить → СБП / карта РФ (от 500₽)

Как вставить ключ в n8n (credential)

  1. Откройте шаблон «Трек А» в своём n8n Cloud
  2. Кликните узел «🤖 Саммаризация (LLM)» → поле Credential → Create New
  3. Name: LLM API (ключ от тренера)
  4. Credential Type: Header Auth
  5. Header Name: Authorization
  6. Header Value: Bearer <ваш-ключ> (для OpenRouter) или Api-Key <ключ> (для AiTunnel)

Для AiTunnel дополнительно

В узле HTTP Request измените URL:

OpenRouter: https://openrouter.ai/api/v1/chat/completions
AiTunnel:  https://api.aitunnel.ru/v1/chat/completions

Google Sheets — персональный аккаунт

Узел «📝 Лента заметок» → Credential → Create New → Google Sheets OAuth2 API. Нажмите Sign In with Google → выберите свой аккаунт → разрешите доступ.

Безопасность API-ключа

  • Никогда не публикуйте ключ в открытых репозиториях, чатах, скриншотах
  • Храните в менеджере паролей или локальном .env-файле
  • Если ключ скомпрометирован — немедленно удалите его в профиле и создайте новый
  • На занятии: ключ тренера ТОЛЬКО в рамках сессии. Дома — свой ключ
Рекомендация тренера: Для занятия и дома — deepseek-v4-flash (самая популярная, быстрая, бесплатная). Для reasoning — stepfun-step-3.5-flash (free). Для длинных текстов (1M+ контекст) — xiaomi-mimo-v2.5 или qwen3-30b-a3b. Все прошли проверку на агентность.

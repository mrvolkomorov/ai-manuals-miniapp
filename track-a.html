Импорт и настройка шаблона «Трек А» в n8n

Трек А — Мониторинг конкурента · v1.2 · 10.09.2026 · Курс «ИИ-инструменты для региональной редакции»

Что делает этот шаблон

Связка «пост конкурента → фильтр по ключевым словам → саммаризация через LLM → запись в Google Таблицу».

После импорта вы меняете только 3 значения, нажимаете Execute — и в таблице появляется первая строка.

Важно: персональная инфраструктура. n8n — ваш персональный n8n Cloud (trial). Google — ваш персональный аккаунт. API-ключ LLM — ключ тренера на занятии, ваш собственный ключ дома.

Скачать шаблон

track_a_template.json — файл из материалов Занятия 1.

Импорт в n8n Cloud

  1. Войдите в свой n8n Cloud (n8n.cloud) — ваш персональный trial-аккаунт
  2. Нажмите Add Workflow → Import from File → выберите track_a_template.json
  3. Шаблон откроется на холсте. Нажмите Save

Три значения, которые нужно заменить

🔴 1. Канал-донор

Узел «📄 Пост-донор (пример)» → поле channel → впишите название канала конкурента. Одновременно замените пример текста в поле text на реальный пост (или оставьте для теста).

🔴 2. Ключевые слова

Узел «🔍 Фильтр по ключевым словам» → откройте условия. Слова по умолчанию: открыт, событие, авария. Замените на свои темы: город, транспорт, ЖКХ, происшествия, открытие, закрытие. Можно добавить/удалить строки условий (кнопка Add condition).

🔴 3. Таблица

Узел «📝 Лента заметок (Sheets)» → поля:

  • documentId — ID вашей Google Таблицы (из ссылки между /d/ и /edit)
  • sheetName — имя листа (обычно «Лист1»)

Подключение учётных данных (credentials)

В шаблоне два узла требуют credentials — они не переносятся с файлом. Создайте их вручную:

LLM API — ключ тренера (на занятии)

Узел «🤖 Саммаризация (LLM)» → поле Credential → Create New.

  • Name: LLM API (ключ от тренера)
  • Credential Type: Header Auth
  • Header Name: Authorization
  • Header Value: Bearer <ключ-от-тренера>

Ключ выдаёт тренер на занятии. Дома замените на свой ключ.

Google Sheets — ваш персональный аккаунт

Узел «📝 Лента заметок (Sheets)» → поле Credential → Create New → Google Sheets OAuth2 API. Нажмите Sign In with Google → выберите свой персональный аккаунт → разрешите доступ.

Проверка (Execute)

  1. Сохраните workflow
  2. Нажмите Execute Workflow (кнопка на узле «▶ Старт»)
  3. Ожидаемый результат: в таблице появилась строка с датой, каналом, темой, саммари и ссылкой
  4. Если строка не появилась — проверьте, прошёл ли пост фильтр по ключевым словам (узел IF: true/false ветка)

Типичные проблемы

ПроблемаРешение
Ошибка 401 в LLMПроверьте формат: Bearer sk-or-... (OpenRouter) или Api-Key ... (AiTunnel)
Ошибка доступа к SheetsПроверьте documentId и права доступа (должен быть Anyone with link или ваш аккаунт)
Пост не прошёл фильтрУзел IF → проверьте ветку false: возможно, ключевые слова не совпадают
Пустая саммаризацияПроверьте модель в HTTP Request — не все модели поддерживают русский

От трека А к реальному мониторингу

Шаблон использует Manual Trigger (кнопка Execute) — для теста. Для реальной работы замените узел «▶ Старт» на:

  • Telegram Trigger — если подключён бот к каналу конкурента
  • Schedule Trigger (каждый час) + RSS Feed / HTTP Request для сбора постов
Ключ на занятии vs дома: на занятии — ключ тренера. Дома — получите свой ключ на OpenRouter или AiTunnel и замените значение в том же credential. Рекомендация для дома: deepseek-v3 (free) — бесплатная модель, не требует пополнения баланса.

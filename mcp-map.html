MCP-серверы

Карта MCP-серверов

Занятие 1 · v1.2 · 10.09.2026 · Курс ИИ-инструменты для региональной редакции

MCP (Model Context Protocol) — универсальный слот, через который ваш ИИ-клиент (LobeHub, Cherry Studio, DeepChat) подключается к внешним сервисам: Telegram, TGStat, поиску в интернете, Google-документам.

Вместо того чтобы писать отдельный код для каждого сервиса — вы один раз настраиваете MCP-сервер и пользуетесь им из любого диалога с ИИ.

1 Telegram MCP (MTProto / Telethon)

Что умеет
  • telegram_list_chats — список чатов и каналов
  • telegram_get_messages — сообщения из чата/канала
  • telegram_search_messages — поиск по всем чатам
  • telegram_send_message — отправка сообщения
  • telegram_get_me — инфо об аккаунте
  • telegram_get_contacts — контакты
Запуск

На Railway. Каждый участник разворачивает свой экземпляр. Нужны: GitHub, Fork репозитория, api_id/api_hash с my.telegram.org, session string (через Replit), 3 переменные на Railway.

Подключение

Name: Telegram MCP · Type: HTTP (Streamable HTTP) · URL: https://[домен].up.railway.app/mcp

2 TGStat MCP

Что умеет (20 инструментов)
  • search_channels / get_channel — поиск и карточка канала
  • get_channel_stats — охваты, ERR, просмотры
  • get_channel_posts — посты канала
  • search_posts — поиск постов по словам
  • get_word_mentions — тренды ключевых слов
  • compare_channels — сравнение каналов
  • get_channel_subscribers / get_channel_views / get_channel_err — динамика
  • get_channel_mentions / get_channel_forwards — упоминания и пересылки
Запуск

На Railway. Деплой mrvolkomorov/tgstat-mcp-http (без Fork). Нужен TGSTAT_TOKEN с api.tgstat.ru.

Подключение

Name: TGStat MCP · Type: HTTP (Streamable HTTP) · URL: https://[домен].up.railway.app/mcp

3 Firecrawl

Что умеет
  • firecrawl_scrape — извлечение содержимого страницы
  • firecrawl_search — веб-поиск
  • firecrawl_crawl — обход сайта по ссылкам
  • firecrawl_map — карта ссылок сайта
  • firecrawl_extract — структурированные данные
  • firecrawl_parse — парсинг PDF, DOCX и др.
Запуск

Облачный сервис. Регистрация на firecrawl.dev. Бесплатный тариф — 500 страниц/мес.

Подключение

URL: https://api.firecrawl.dev/mcp + API-ключ в заголовке. Или через Composio.

4 Tavily

Что умеет
  • tavily_search — поиск в интернете (фильтры по времени, доменам, стране)
  • tavily_extract — извлечение содержимого по URL
  • tavily_crawl — обход сайта
  • tavily_map — карта ссылок
  • tavily_research — глубокое исследование темы
Запуск

Облачный сервис. Регистрация на tavily.com. Бесплатный тариф — 1000 запросов/мес.

Подключение

URL: https://api.tavily.com/mcp + API-ключ. Или через Composio.

5 Composio (Google-сервисы и 500+ приложений)

Что умеет (основное для курса)
  • Google Sheets — чтение и запись таблиц (лента заметок, дашборды)
  • Google Docs — создание и редактирование документов
  • Gmail — отправка и чтение писем
  • Google Drive — загрузка и управление файлами
  • Google Calendar — работа с календарём
  • Slack, GitHub, Telegram Bot и 500+ других приложений
Запуск

Облачный сервис. Регистрация на composio.dev. Подключение приложений через OAuth (Google — один клик).

Подключение

URL из Composio + session_id. Для Google Sheets дополнительно: авторизация через Sign In with Google.

Правила безопасности

  • Telegram MCP: session string = доступ к вашему аккаунту. Храните в Railway Variables (зашифровано), никому не передавайте
  • TGStat MCP: токен привязан к подписке. Не публикуйте в открытых чатах
  • Firecrawl / Tavily: API-ключи храните в настройках ИИ-клиента. Не вставляйте в промпты
  • Composio: отзывайте доступ к приложениям, если больше не используете
  • Общее правило: MCP-сервер даёт ИИ доступ к вашим данным. Подключайте только те серверы, которые реально нужны для задачи

Как получить API ID и API Hash Telegramдля пользователей из РФ

v1.0 · 16.09.2026 · Курс ИИ-инструменты для региональной редакции
Проблема: Сайт my.telegram.org в России не открывается без VPN. А если зайти через VPN, Telegram видит, что ваш номер российский (+7), а IP-адрес зарубежный, и выдаёт ошибку ERROR.

Причина: блокировка работает на уровне DNS. Провайдер не отдаёт правильный IP-адрес сайта. Но сам сайт при этом доступен, если подсказать компьютеру нужный IP вручную.

Решение: внести одну строчку в файл hosts — сайт откроется с вашего обычного российского IP.

Решение 1 (основное): добавить строчку в файл hosts

Этот способ работает у большинства пользователей. Выполните все шаги последовательно.

1 Проверьте, подойдёт ли вам этот способ

Проверьте, разрешает ли ваш провайдер подключение к сайту Telegram напрямую.

Windows
  1. Нажмите Win, начните печатать cmd
  2. В результатах поиска нажмите на Командная строка правой кнопкой → Запуск от имени администратора
  3. Вставьте команду и нажмите Enter:
curl -sv --connect-timeout 5 -m 15 --resolve my.telegram.org:443:149.154.167.220 https://my.telegram.org -o NUL
Mac
  1. Command + пробел → напишите Терминал → Enter
  2. Вставьте команду и нажмите Enter:
curl -sv --connect-timeout 5 -m 15 --resolve my.telegram.org:443:149.154.167.220 https://my.telegram.org -o /dev/null
Что смотреть в результате
  • HTTP/2 200 или HTTP/1.1 302 в самом конце → ✅ отлично, способ подходит, переходите к Шагу 2
  • Failed to connect или Connection timed out → ❌ провайдер блокирует сам IP-адрес. Переходите к Решению 2
  • Connection reset или ошибка SSL → ❌ способ не подходит
2 Отключите VPN

Если на вашем компьютере или телефоне включён VPN — полностью отключите его. Сайт должен открываться с вашего обычного российского IP.

3 Откройте файл hosts для редактирования
Windows 10 / 11
  1. Нажмите Win → напишите Блокнот → правой кнопкой → Запуск от имени администратора
  2. В Блокноте: Файл → Открыть
  3. Перейдите в папку: C:\Windows\System32\drivers\etc
  4. Важно: в правом нижнем углу переключите фильтр с «Текстовые документы (.txt)» на «Все файлы (.)»
  5. Выберите файл hosts (без расширения) → Открыть
  6. Курсор в самый конец файла → Enter
  7. Вставьте строчку:
149.154.167.220 my.telegram.org
  1. Файл → Сохранить (Ctrl + S)
Типичная ошибка: Блокнот сохраняет файл как hosts.txt. Так файл не будет работать. Если столкнулись — закройте Блокнот, откройте заново от администратора, снова откройте hosts и при сохранении в поле «Имя файла» напишите в кавычках: "hosts". Убедитесь, что в папке нет двух файлов — hosts и hosts.txt.
Mac
  1. Откройте Терминал (Command + пробел → Терминал)
  2. Введите команду:
sudo nano /etc/hosts
  1. Введите пароль пользователя (символы не отображаются — нормально)
  2. Стрелками переместите курсор в конец файла → Enter → вставьте строчку:
149.154.167.220 my.telegram.org
  1. Сохраните: Control + O (именно Control, не Command) → Enter
  2. Выйдите: Control + X
4 Очистите кэш DNS
Windows
ipconfig /flushdns
Mac
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder
5 Полностью закройте и заново откройте браузер

Закройте не просто вкладку, а весь браузер целиком.

Windows: Ctrl + Shift + Esc → Диспетчер задач → найдите браузер → правой кнопкой → Завершить задачу. Mac: Command + Q.

6 Зайдите на сайт и получите ключи
  1. Откройте браузер → my.telegram.org (сайт должен открыться)
  2. Введите номер: +7XXXXXXXXXX → Next
  3. Введите код из Telegram
  4. Нажмите API Development Tools
  5. Заполните форму (см. раздел «Как правильно заполнить форму» ниже)
  6. Нажмите Create Application
  7. Скопируйте App api_id и App api_hash — сохраните в надёжном месте
7 Верните файл hosts в исходное состояние (обязательно!)
Важно: После получения ключей обязательно удалите добавленную строчку из файла hosts. Если этого не сделать — когда Telegram в будущем сменит IP-адрес сервера, сайт перестанет открываться вообще.

Повторите действия Шага 3, только на этот раз удалите строчку 149.154.167.220 my.telegram.org и сохраните файл. Затем очистите DNS-кэш (Шаг 4).

Как правильно заполнить форму

Критически важно: даже если сайт открылся и вы авторизовались, многие получают ошибку из-за неправильного заполнения формы. Telegram не показывает, какое именно поле вызывает ошибку — просто выдаёт ERROR.

Решение 2: VPN через Казахстан или Узбекистан

Некоторые пользователи из России сообщают, что через VPN с IP Казахстана или Узбекистана получить ключи удаётся. Работает не всегда, но проверенный вариант.

  • Подключите VPN с сервером в Казахстане или Узбекистане
  • Зайдите на my.telegram.org
  • Авторизуйтесь и заполните форму
  • Нажмите Create Application

Решение 3: Cloudflare WARP

Бесплатный сервис, который иногда помогает обойти DNS-блокировку без смены IP на зарубежный.

  • Перейдите на 1.1.1.1
  • Скачайте и установите приложение для вашей ОС
  • Запустите и включите
  • Зайдите на my.telegram.org и попробуйте создать приложение

Решение 4: комбинированный способ

  1. Включите VPN и зайдите на my.telegram.org
  2. Авторизуйтесь, заполните форму, но не нажимайте Create Application
  3. Отключите VPN
  4. Отредактируйте файл hosts (как в Шаге 3)
  5. Очистите DNS-кэш (как в Шаге 4)
  6. Теперь нажмите Create Application — запрос уйдёт с вашего российского IP

Чего точно НЕ стоит делать

  • Не пытайтесь сделать это 20 раз подряд. Telegram временно заблокирует ваш аккаунт от создания приложений (на несколько часов или сутки)
  • Не используйте короткие имена. Short name короче 5 символов — гарантированная ошибка
  • Не называйте приложение TelegramParser, MassSender, ScraperBot — такие названия вызывают автоматическую блокировку
  • Не оставляйте запись в файле hosts навсегда — когда Telegram сменит IP сервера, сайт перестанет работать
  • Не тратьте время на поддержку Telegram — они не отвечают на такие запросы

Термины сгруппированы по темам: от простых к продвинутым. Каждый термин — короткое «что это» и фраза «как применять».

🧠 1. ИИ и модели

LLM Large Language Model
Нейросеть, которая понимает и генерирует текст. ChatGPT, DeepSeek, Qwen, Gemini — всё это LLM.
→ В метафоре «кухни» — повар.
Токен Token
Единица текста, которую LLM читает или пишет. ~1 токен ≈ ¾ русского слова. Стоимость LLM измеряется в $/1M токенов.
→ Чем больше токенов — тем дороже каждый запрос.
Контекстное окно Context Window
Сколько текста LLM «помнит» в одном разговоре (128K, 256K, 1M). Чем больше — тем длиннее документ можно скормить разом.
→ Для длинных документов выбирайте модели с 1M+ контекста.
Следование инструкции Instruction Following
Насколько точно модель выполняет то, что вы попросили (роль, формат, запреты). Ключевое качество для автоматизации.
→ Если модель «своевольничает» — сценарий ломается.
Reasoning-модель размышляющая модель
LLM, которая «думает» перед ответом (видно блок «Thinking»). DeepSeek-R1, Step 3.5 Flash.
→ Хороша для сложного анализа, но медленнее и дороже обычных.
MoE Mixture of Experts
Архитектура, где работают не все параметры сразу, а только часть. Делает модель дешёвой и быстрой без потери качества.
→ LongCat, Step Flash, DeepSeek V4 — MoE-модели.
Бесплатная модель Free Model
Модель на OpenRouter с нулевой ценой. Есть лимиты запросов (50–1000/сутки).
→ Подходит для обучения и тестов: Step 3.5 Flash, LongCat 2.0.

🔌 2. MCP и агенты

MCP Model Context Protocol
Стандарт подключения внешних сервисов к ИИ. Как USB-разъём: один раз подключили Telegram — и он доступен в любом диалоге.
→ В метафоре «кухни» — дверь в кладовую.
MCP-сервер
Программа, которая связывает ИИ с внешним сервисом (Telegram, TGStat). Работает круглосуточно на Railway.
→ Каждый участник разворачивает свой экземпляр.
Агент Agent / ИИ-агент
Настроенный ИИ-помощник с системной инструкцией и MCP-серверами. Работает по правилам: роль, алгоритм, формат выдачи, запреты.
→ В отличие от чата — агент не задаёт уточняющих вопросов.
Агентный клиент
Приложение, в котором создаются агенты и подключаются MCP. LobeHub, Cherry Studio, DeepChat.
→ В метафоре «кухни» — официант.
Системная инструкция System Prompt
Набор правил, которые агент выполняет всегда — без напоминаний. Задаётся один раз при создании: роль, контекст, алгоритм, формат, запреты.
→ Это «паспорт» агента.
MTProto / Telethon
Протокол, через который MCP-сервер подключается к вашему Telegram-аккаунту от вашего имени. Даёт доступ к чатам и каналам (в отличие от Bot API).
→ Используется для Telegram-MCP.
Session String
«Ключ сессии» — связывает MCP-сервер с вашим Telegram-аккаунтом. Генерируется через Replit. Хранится в зашифрованных переменных Railway.
→ Никому не передавать!

⚙️ 3. Автоматизация (n8n)

Workflow воркфлоу
Последовательность шагов, которые n8n выполняет автоматически. На холсте — цепочка соединённых нод.
→ В метафоре «кухни» — рецепт.
Нода Node
Один шаг в workflow: триггер, фильтр, HTTP-запрос, запись в таблицу. Соединяются линиями, данные текут слева направо.
→ Каждая нода делает одно действие.
Триггер Trigger
Нода, которая запускает workflow: Execute (ручной), Schedule (по расписанию), Webhook (по событию).
→ На занятии используем Execute для тестов.
Execute
Ручной запуск workflow — кнопка ▶ на первой ноде.
→ Нажал → посмотрел → поправил → снова Execute.
Schedule расписание
Триггер по времени: каждый час, раз в день, по понедельникам в 9:00.
→ Для регулярных задач — замените Manual Trigger на Schedule.
Фильтр IF
Нода с условием: true (пропускаем) или false (игнорируем). Например: «в тексте есть слово "открытие"?».
→ Для отсева ненужных постов.
HTTP Request
Нода, которая отправляет запрос к внешнему сервису — например, к LLM через OpenRouter.
→ Основной способ вызвать нейросеть из n8n.
Credential учётные данные
Сохранённый ключ доступа: API-ключ LLM, пароль Google, токен Telegram. Создаётся один раз для всех workflow.
→ Не переносится при импорте шаблона.
Header Auth
Тип credential для LLM. В заголовке передаётся: Authorization: Bearer <ключ>.
→ Стандартный формат для OpenRouter и AiTunnel.
OAuth / OAuth2
Авторизация через «Войти с Google». Безопасно, без передачи пароля.
→ Используется для Google Sheets в n8n.
NoOp No Operation
Нода-заглушка «ничего не делать». Ставится в false-ветку фильтра.
→ Чтобы workflow не падал, когда условие не сработало.
Sticky Note
Заметка на холсте n8n. Не влияет на работу.
→ Для подсказок: «🔴 ЗАМЕНИТЕ это значение».
JSON
Формат данных для передачи между нодами: выглядит как {} с ключами и значениями.
→ n8n передаёт данные между нодами в JSON.
Webhook
Триггер по внешнему сигналу: кто-то отправил запрос на URL → n8n запустил workflow.
→ Для интеграций с Telegram-ботами и внешними сервисами.
Polling опрос
Режим: n8n сам периодически проверяет источник — «есть новое?».
→ Отличается от Webhook тем, что n8n сам ходит за данными.
Батч Batch
Обработка пачкой: 50 постов за раз вместо одного.
→ Экономит время и токены.

🌐 4. Платформы и сервисы

OpenRouter
Единый провайдер доступа к 300+ LLM через один API-ключ. Бесплатные модели без пополнения.
→ openrouter.ai
AiTunnel
Российский провайдер LLM с оплатой в рублях. Без VPN. Пополнение через СБП.
→ aitunnel.ru
Railway
Платформа для запуска серверов в облаке. Используется для MCP-серверов. Бесплатный тариф — $5/мес.
→ Деплой из GitHub в 1 клик.
TGStat
Сервис аналитики Telegram-каналов: подписчики, охваты, ERR, динамика. Через MCP — 20 инструментов.
→ tgstat.ru (платная подписка).
Deepgram
Сервис расшифровки аудио/видео в текст. Русский язык, различает говорящих, таймкоды.
→ ~$200 бесплатных кредитов при регистрации.
Figma / Supa / Gamma
Инструменты для визуального контента с ИИ. Работают в браузере.
→ Figma для дизайна, Supa и Gamma — для презентаций.
Replit
Браузерная среда для запуска кода. Без установки Python.
→ Используется один раз — для генерации Session String.

📊 5. Метрики и аналитика

ERR Engagement Rate by Reach
Коэффициент вовлечённости: (реакции / охват) × 100%. Высокий ERR = контент попал в аудиторию.
→ Ключевая метрика качества контента.
Охват Reach
Сколько уникальных пользователей увидели пост.
→ Отличается от просмотров (один человек может посмотреть много раз).
Динамика
Изменение метрики во времени: график или таблица помесячно/понедельно.
→ Позволяет увидеть тренд — где перелом?
Гипотеза в контексте аналитики
Проверяемое предположение о том, что влияет на охваты. Формула: «Публикации с [X] получают в N раз больше охватов, чем [Y]».
→ Без гипотезы данные — просто цифры.

🎨 6. Контент и визуал

Кросс-постинг
Автоматическая адаптация одного материала под несколько площадок (VK, Telegram, Дзен). У каждой — свой тон, длина, структура.
→ Не путать с репостом — кросс-постинг адаптирует контент.
«1 → 5»
Сценарий: из одного исходного текста генерируются 5 черновиков: VK, Telegram, ОК, Дзен + анонс.
→ Максимальная утилизация одного материала.
CTA Call to Action
Призыв к действию в конце поста: «Подпишитесь», «Перейдите по ссылке».
→ Без CTA пост — просто информация.
Чанкинг Chunking
Разбиение длинного текста на смысловые блоки. Каждый чанк = одна мысль.
→ Используется при формировании карточек из расшифровки.
Диаризация Diarization
Различение говорящих при расшифровке: «Speaker 1», «Speaker 2».
→ Позволяет понять, кто что сказал в интервью.
Inpaint / Outpaint
Inpaint — заменить или убрать объект внутри картинки. Outpaint — дорисовать за пределами границ.
→ Inpaint: убрать логотип. Outpaint: расширить фон.
Restyle рестайл
Перенос стиля: перекрасить чужую инфографику под цвета и шрифты вашего бренда.
→ Текст и логотип — только руками.
Редакторская нормализация
Сжатие текста: убрать «воду», сохранить факты и цифры. Объём — минус 40%.
→ Промпт №6 в библиотеке.

🔒 7. Безопасность

API-ключ
Секретный код доступа к сервису. Как пароль от аккаунта.
→ Не публиковать в чатах, скриншотах и репозиториях.
OAuth / OAuth2
Безопасная авторизация без передачи пароля. «Войти с Google» — это OAuth.
→ Приложение получает доступ только к тому, что вы разрешили.
Prompt Injection
Атака: пользователь вставляет команду, переопределяющую системную инструкцию.
→ Защита — жёсткие запреты в system prompt.
Human-in-the-loop
Принцип: автоматизация готовит черновик, человек принимает решение.
→ Автоматическая публикация без человека — запрещена.
NDA Non-Disclosure Agreement
Документы, которые нельзя показывать третьим лицам — в том числе ИИ.
→ Не загружайте NDA-материалы в облачные сервисы.
Обезличивание
Замена реальных данных (названий, сумм, ИНН) на плейсхолдеры [ОРГАНИЗАЦИЯ], [СУММА].
→ Обязательно для NDA-материалов и персональных данных.

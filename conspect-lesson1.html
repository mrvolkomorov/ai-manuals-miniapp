Настройка инфраструктуры ИИ-агента: Telegram, Railway, OpenRouter

Занятие 16.09.2026 · Курс ИИ-инструменты для региональной редакции

1. Архитектура ИИ-агента: анатомия

ИИ-агент — система, которая самостоятельно выполняет задачи через нейросети. Состоит из трёх компонентов:

  • Мозг — нейросеть (языковая модель), которая принимает решения и генерирует ответы. Подключается через агрегаторы: OpenRouter (500+ моделей, международный стандарт) или AITunnel (российский аналог, оплата в рублях)
  • Туловище — приложение-агрегатор, где собирается агент. Пример: LobeHub (китайское приложение, доступно в браузере бесплатно). Здесь настраивается роль, инструкции и подключаются инструменты
  • Гаечные ключи — MCP-серверы (коннекторы), которые дают агенту доступ к внешним сервисам: Telegram-сервер (чтение каналов, отправка сообщений), TGStat-сервер (статистика), другие инструменты (Google Docs, поиск)
  • Навыки (скиллы) — текстовые инструкции, которые объясняют агенту, как пользоваться инструментами. Без них агент, имея мозг и ключ, не знает, как им пользоваться

2. GitHub: аккаунт и форк репозитория

GitHub — главный ресурс для разработчиков, где хранятся приложения с открытым кодом.

  1. Создать аккаунт на github.com через Google
  2. Перейти по ссылке на репозиторий с Telegram-сервером
  3. Нажать Fork — создать свою копию
Проблема: при массовой регистрации с одного IP (из офиса) GitHub выдаёт ошибку превышения лимита запросов. Решение: повторить позже или с другого IP.

3. Получение доступов Telegram

Для подключения агента к Telegram как пользователю (не боту) нужны три значения: API ID, API hash, Session string.

Шаг 1. my.telegram.org → API Development Tools

Создать приложение: платформа Web, название любое (MyMCP). Нажать Create application, сохранить API ID и API hash.

Шаг 2. Session string через Google Colab

Последовательно запустить ячейки, ввести API ID, API hash, код из Telegram и пароль двухфакторной аутентификации. Сохранить длинную строку session string.

Проблема: у большинства участников возникала ошибка при создании приложения. Возможные причины: VPN, расширения браузера (блокировщики), Яндекс.Браузер. Успешно прошли шаг через Google Chrome без расширений; у Арины получилось с телефона.

4. Развёртывание серверов на Railway

Railway — сервис для быстрого развёртывания приложений из GitHub.

Процесс для Telegram-сервера:

  1. Зарегистрироваться на railway.com через Google (триал 30 дней)
  2. New Project → Deploy from GitHub repo → вставить ссылку на свой Fork
  3. Settings → Variables → добавить: tg_api_id, tg_api_hash, tg_session_string
  4. Нажать Deploy, дождаться сборки
  5. Settings → Networking → Generate Domain → сохранить полученную ссылку

Для TGStat-сервера — аналогично: вставить свой Fork TGStat-сервера и переменную tgstat_token.

Проблема: при ошибке Failed to build проверьте имя переменной — нижние подчёркивания важны (tg_api_id, а не tgapiid).

5. DeepGram: транскрибация аудио и видео

DeepGram (playground.deepgram.com) — сервис для превращения звука и видео в текст.

  • Поддержка русского языка — отлично работает
  • Несколько моделей: Whisper (OpenAI), Nova (Amazon)
  • Smart Format — автоматическое разбиение на абзацы
  • Пунктуация и параграфы
  • Принимает и видеофайлы

Процесс: регистрация через Google или GitHub (кредит $200). Playground → Speech to Text → Pre-recorded → Upload Audio. Выбрать русский язык, модель, отметить Smart Format, пунктуацию, параграфы → Run.

Для больших видео рекомендуется извлечь аудиодорожку в видеоредакторе (OpenShot и др.) — будет быстрее.

6. Сборка агента в LobeHub

LobeHub — приложение для создания ИИ-агентов, работает в браузере (lobehub.com).

Подключение нейросетей:

  1. Авторизоваться в LobeHub (через Google)
  2. Зайти в настройки поставщиков
  3. Выбрать OpenRouter
  4. Вставить API-ключ и URL proxy API: https://openrouter.ai/api/v1
  5. Нажать «Загрузить модели»
  6. Включить нужные модели переключателем
Модель агента: мозг (нейросеть через OpenRouter) + туловище (LobeHub) + гаечный ключ (Telegram/TGStat-серверы на Railway) + навыки (инструкции агенту).

7. Экономика нейросетей

Два способа оплаты:

  • Подписка — фиксированная сумма в месяц (ChatGPT Plus $20). Ограниченный лимит токенов
  • API-ключи — оплата за фактическое использование через OpenRouter или AITunnel

Стоимость за 1 млн токенов (выход):

МодельЦена
DeepSeek~$0.14 — дешёвая, хорошо соображает
Qwen Max~$0.94 — китайская модель
GPT$10.00 — премиум
Claude$15.00 — премиум

Расход токенов на практике:

  • Транскрибация 3 часов разговора ≈ 1 млн токенов
  • Небольшая задача агента ≈ 150–200 тыс. токенов
  • Масштабный проект с агентом — 1–2 млн токенов за час

8. Инструменты без зарубежной карты

  • AITunnel.ru — российский агрегатор, оплата в рублях. Тот же принцип, что у OpenRouter, но меньше выбор моделей. Есть встроенный чат для общения с разными моделями
  • Сингапурская карта — самый удобный вариант (8–10 долларов за выпуск, налоги не добавляются). Европейские карты могут добавлять 2–3 доллара налогов к подписке. Claude может отклонять даже такие карты

9. Безопасность

  • Данные для доступа к Telegram (API ID, API hash, session string) хранятся как секреты на Railway — их видите только вы и приложение
  • Форки клиентов Telegram (Nicegram и др.) — непроверенные приложения, могут использовать ваши данные
  • Для OpenRouter API-ключ показывается только один раз при создании — сразу сохраните в надёжное место

10. Дальнейшие шаги

На следующем занятии:

  1. Соединить мозг (OpenRouter), туловище (LobeHub) и гаечные ключи (Telegram/TGStat)
  2. Настроить навыки — инструкции для агента
  3. Собрать работающего агента, который сможет получать и анализировать данные из Telegram
Домашнее задание: повторить весь пройденный путь — создать GitHub, получить доступы Telegram, развернуть серверы на Railway, подключить TGStat и нейросети к LobeHub.

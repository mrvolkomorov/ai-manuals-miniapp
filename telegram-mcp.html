Развёртывание Telegram-MCP на Railway

telegram-mcp-http · v1.1 · 14.09.2026 · Курс «ИИ-инструменты для региональной редакции»

Что мы делаем и зачем

Разворачиваем собственный MCP-сервер для Telegram на платформе Railway. После развёртывания ваш ИИ-клиент (LobeHub, Cherry Studio, DeepChat) сможет читать ваши чаты Telegram, искать сообщения, отправлять сообщения — от вашего имени.

Каждый участник разворачивает СВОЙ сервер, подключённый к СВОЕМУ Telegram-аккаунту.

Никакой технической подготовки не нужно. Мы проходим каждый шаг впервые. Внимательно следуйте инструкции — всё получится. Итого времени: 10–15 минут.

Обзор шагов (5 шагов)

  1. Создать аккаунт на GitHub (3 мин)
  2. Сделать Fork репозитория (1 мин)
  3. Получить api_id и api_hash для Telegram (3 мин)
  4. Сгенерировать session string (3 мин)
  5. Развернуть на Railway и подключить (3 мин)

Шаг 1. Создать аккаунт на GitHub

GitHub — это хранилище кода. Аккаунт бесплатный.

  1. github.com → Sign up
  2. Введите email (любой, к которому есть доступ)
  3. Придумайте пароль (запишите!)
  4. Придумайте username — например, ivanov-smm
  5. Подтвердите email кодом из письма
  6. Пройдите опрос (Skip personalization)

Шаг 2. Сделать Fork репозитория

Fork — это копия репозитория тренера в вашем аккаунте. Одна кнопка.

  1. Зайдите на github.com/mrvolkomorov/telegram-mcp-http
  2. В правом верхнем углу нажмите кнопку Fork
  3. Нажмите Create fork

Готово: у вас есть своя копия по адресу github.com/ВАШ-USERNAME/telegram-mcp-http.

Шаг 3. Получить api_id и api_hash

Эти данные нужны, чтобы сервер мог подключиться к вашему Telegram-аккаунту от вашего имени.

  1. Зайдите на my.telegram.org
  2. Введите номер телефона, привязанный к вашему Telegram
  3. Введите код подтверждения из Telegram/SMS
  4. Вы попадёте в раздел «API development tools»
  5. Заполните: App title = MyMCP, Short name = mymcp, Platform = Desktop
  6. Нажмите Create application
  7. Скопируйте api_id (число) и api_hash (строка букв и цифр)
Внимание: api_hash — секретный ключ. Никому его не передавайте. Скопируйте и сохраните в блокноте.

Шаг 4. Сгенерировать session string

Session string — это «ключ сессии», который связывает сервер с вашим Telegram-аккаунтом. Есть два способа.

Способ А — через Colab (рекомендуется, без установки программ)
  1. Зайдите на replit.com и войдите в Google-аккаунт
  2. File → Open notebook → GitHub → вставьте ссылку github.com/ВАШ-USERNAME/telegram-mcp-http
  3. Откройте файл generate_session.py
  4. Замените API_ID = 0 и API_HASH = "" на ваши данные из Шага 3
  5. Нажмите зелёную кнопку Run
  6. Введите номер телефона в формате +79001234567
  7. Введите код из Telegram (код НЕ отображается при вводе — это нормально)
  8. Если включена двухфакторка — введите пароль
  9. Скопируйте длинную строку (начинается с 1) — это ваш session string
Способ Б — локальный (если уже установлен Python)
  1. Скачайте generate_session.py из репозитория
  2. Впишите ваши API_ID и API_HASH
  3. В терминале: python generate_session.py
  4. Далее — как в пунктах 6–9 способа А

Шаг 5. Развернуть на Railway

Railway — платформа, где ваш сервер будет работать 24/7. Есть бесплатный тариф ($5 кредитов в месяц).

  1. Зайдите на railway.com → Start a New Project → Login with GitHub
  2. New Project → Deploy from GitHub repo
  3. Разрешите Railway доступ к вашему GitHub (Install Railway) — выберите только репозиторий telegram-mcp-http
  4. Нажмите Deploy Now (1–2 минуты)
  5. Когда зелёный статус: вкладка Variables
  6. Добавьте ТРИ переменные:
TG_API_ID        = ваш api_id (только число, без кавычек)
TG_API_HASH      = ваш api_hash (строка без кавычек)
TG_SESSION_STRING = ваш session string (вся длинная строка)
  1. Railway автоматически перезапустит сервер (30 сек)
  2. Settings → Networking → Generate Domain
  3. Скопируйте адрес вида https://telegram-mcp-http-production.up.railway.app

Проверка работоспособности

Откройте в браузере: https://telegram-mcp-http-production.up.railway.app/health

Должно отобразиться: {"status": "ok"}

Подключение к ИИ-клиенту

  1. Откройте настройки MCP-серверов
  2. Добавьте: Name = Telegram MCP, Type = HTTP (Streamable HTTP), URL = https://ваш-домен/mcp
  3. Сохраните и включите

В чате с ИИ теперь доступны 6 инструментов: чтение чатов, поиск сообщений, отправка сообщений и др.

Типичные проблемы

ПроблемаРешение
Ошибка 401Проверьте TG_API_ID и TG_API_HASH
Ошибка AUTH_KEY_DUPLICATEDСгенерируйте новый session string
Ошибка 503 / 404Подождите 1 мин (сервер запускается)
Не видит инструментыURL должен заканчиваться на /mcp

Безопасность

  • api_hash и session string — секретные. Никому не передавайте
  • Храните их в блокноте на компьютере, не в публичных чатах
  • Если заподозрили утечку: my.telegram.org → API development tools → Revoke session
  • На Railway переменные зашифрованы и не отображаются в логах

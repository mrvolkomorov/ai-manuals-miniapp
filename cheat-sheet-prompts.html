Промпты и шаблоны

Библиотека аналитических промптов

Cheat-sheet · 14 шаблонов · v1.2 · 10.09.2026 · Курс ИИ-инструменты для региональной редакции

14 готовых шаблонов для SMM и редакции. Все промпты построены по структуре Роль → Задача → Данные → Формат → Контекст.

Подставляйте свои каналы, темы и ключевые слова в места [В СКОБКАХ].

Как пользоваться: копируйте промпт в свой ИИ-клиент (LobeHub, ChatGPT, DeepSeek) — начинайте новый чат для каждого промпта. Для TGStat-промптов нужен запущенный MCP-сервер TGStat. Промпты можно комбинировать.

1 Дашборд своего канала (динамика + обсуждения)

Блок 1 занятия. Аналитический отчёт по вашему Telegram-каналу.

Промпт
Ты — главный аналитик редакции. Через MCP Telegram возьми посты канала [КАНАЛ] за последние 30 дней. Сведи в таблицу: тема / формат / охваты / реакции / комментарии. Выдели топ-5 и дно-5 по охватам. Для топа и дна — по 1 гипотезе «почему так».

2 Конкурентный анализ (MCP + TGStat)

Блок 2 занятия. Сравнение «мы vs конкуренты» с цифрами.

Промпт
Ты — главный аналитик редакции. Через MCP Telegram возьми посты каналов [КАНАЛ_1] и [КАНАЛ_2] за последние 30 дней. Через TGStat получи динамику подписчиков за 6 месяцев, средний охват поста, ERR по каждому каналу. Сведи в сравнительную таблицу: тематические доли, форматы, частота постов, охваты. Выдели, что у конкурента растёт, а что падает.

3 Гипотеза «Что сработало / что провалилось»

Формула гипотезы для еженедельного анализа.

Промпт
Ты — главный аналитик редакции. По дашборду моего канала за последние 30 дней: 1) Выдели 2 публикации с максимальными охватами и 2 с минимальными. 2) Сравни их по: теме, формату, времени публикации, длине текста, наличию визуала, заголовку. 3) Сформулируй гипотезу по формуле: «Публикации с [X] получают в N раз больше охватов, чем [Y], потому что [ГИПОТЕЗА]».

4 Эфир/видео в серию карточек

Одна запись 5 готовых постов.

Промпт
Вот расшифровка эфира или видео (15 мин). Выдели 5 самостоятельных мыслей. Каждую оформи карточкой Telegram: заголовок ≤6 слов, 3-5 строк текста, цитата спикера. Плюс один длинный пост-колонку (700-1000 знаков). Шаг 2: к самой сильной карточке — короткий анонс (2-3 предложения) со ссылкой; к длинному посту — версия без воды минус 40%.

5 Анонс со ссылкой на полный материал

Короткий промпт для быстрого анонса.

Промпт
Ты — SMM-редактор. У меня есть материал на тему [ТЕМА]. Напиши короткий анонс (2-3 предложения), который: даёт понять о чём материал; объясняет кому будет полезно; заканчивается мягким CTA. Варианты: короткий (до 200 зн.), средний (до 500 зн.), с цитатой автора.

6 Редакторская нормализация убрать воду

Для длинных текстов, которые нужно сжать в редакционный стандарт.

Промпт
Ты — главный редактор. Вот текст [ВСТАВИТЬ ТЕКСТ]. Нормализуй его: убери вводные конструкции, повторения, оценочные суждения; проверь что все утверждения подкреплены фактами или ссылками; сохрани термины, имена, даты, цифры; сделай короче на 30% без потери смысла; формат: 3-5 абзацев по 2-3 предложения.

7 Рерайт текста под площадку

Адаптация одной публикации под Telegram, Дзен и VK.

Промпт
Вот материал: [ТЕКСТ]. Адаптируй его для трёх площадок: Telegram — коротко, разговорно, 400-600 зн., 1 абзац + эмодзи. Дзен — заголовок-вопрос, лид-абзац (кто? что? где?), 1500-2000 зн., подзаголовки. VK — эмоциональный лид, 3-5 абзацев, вопрос в конце для комментариев.

8 Что обсуждают по теме (TGStat)

Поиск упоминаний и тональность вокруг ключевой темы.

Промпт
Ты — главный аналитик редакции. Через TGStat получи тренд упоминаний за 30 дней по слову [КЛЮЧЕВОЕ_СЛОВО]. Разбей по каналам. Выдели: какой канал пишет чаще всего; какие посты собрали максимум охватов; сменилась ли тональность за период; какая тема в теме сейчас на пике.

9 Классификатор релевантности по региону

Отсев постов по гео-привязке.

Промпт
Ты — редактор регионального СМИ. Вот список постов: [СПИСОК_ПОСТОВ]. Отметь для каждого: релевантен / не релевантен региону [РЕГИОН]. Критерии: прямое упоминание города или района, события в регионе, участие региональных спикеров. Итог: таблица с колонками Пост / Релевантность / Комментарий.

10 Сравнительный дашборд конкурентов (TGStat)

Глубокое сравнение 2-5 каналов с трендами.

Промпт
Ты — главный аналитик редакции. Через TGStat сравни каналы [КАНАЛЫ — 2-5 штук] за 6 месяцев. Построй таблицу: подписчики (сейчас + прирост), средний охват, ERR, индекс цитирования, средняя частота постов. Выдели канал с макс. приростом подписчиков и канал с макс. ERR. Через MCP Telegram возьми 3 самых охватных поста за месяц у лидера.

11 Адаптер 1 материал 5 форматов

Максимальная утилизация одного материала.

Промпт
Вот материал (текст / интервью / видео / пресс-релиз): [ССЫЛКА_ИЛИ_ТЕКСТ]. Проанализируй и создай 5 форматов: 1) Новостная заметка (300-500 зн.); 2) Пост в Telegram (400-500 зн.); 3) Карточка-цитата; 4) Пост в VK; 5) Сюжет для Дзен (2000-2500 зн.). Для каждого формата — пояснение почему это сработает на этой площадке.

12 Сторис-шаблон 3 конструкции

Быстрые варианты для сторис в соцсетях.

Промпт
Ты — SMM-редактор. По теме [ТЕМА] напиши 3 варианта сторис: Вариант A — За кулисами: покажи процесс, человеческий фактор. Вариант B — Полезный совет: короткий лайфхак. Вариант C — Реакция на новость: займи позицию, пригласи к дискуссии. Каждая — до 200 зн., с призывом.

13 Поиск инфоповодов

Ежедневный поиск тем для постов на основе повестки.

Промпт
Ты — редактор регионального СМИ. Просканируй мои каналы-доноры из MCP Telegram (список [СПИСОК_КАНАЛОВ]) за последние 24 часа. Отбери 5 самых перспективных инфоповодов для региона [РЕГИОН]. Для каждого: чем важен для региона; что мы можем добавить своего; какой формат использовать; пример заголовка.

14 Еженедельный дайджест канала

Автоматический отчёт для редакционной планерки.

Промпт
Ты — главный аналитик редакции. Возьми посты из MCP Telegram канала [КАНАЛ] за последние 7 дней. Создай дайджест: сколько постов вышло / каких форматов; суммарные охваты за неделю, +/- к прошлой неделе; топ-3 поста недели (охваты + почему сработали); анти-топ-1 (низкие охваты + гипотеза почему); 2 инсайта для планерки.

Правила использования

  1. Подставляйте свои данные в [СКОБКИ]
  2. Промпты можно комбинировать: например, №3 + №10 = конкурентный анализ с гипотезой
  3. Для TGStat-промптов нужен запущенный MCP-сервер TGStat
  4. Все промпты проверены на агентность (следование инструкции, предсказуемый формат)
  5. Копируйте в свой ИИ-клиент (LobeHub, ChatGPT, DeepSeek и т.п.) — начинайте новый чат для каждого промпта
Совет: сохраните эту страницу в закладки. Возвращайтесь к ней, когда нужно быстро написать аналитику, анонс, рерайт или найти инфоповод. Промпты №1, №2, №10 и №14 — самые частые в ежедневной работе.

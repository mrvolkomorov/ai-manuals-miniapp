Чек-лист запуска n8n

8 шагов от регистрации до первого запуска · v1.2 · 10.09.2026 · Курс ИИ-инструменты для региональной редакции
Как пользоваться: каждый пункт — шаг, который нужно выполнить, прежде чем переходить к следующему. Пункты 1–3 делаются один раз (регистрация). Пункты 4–8 — каждый раз, когда запускаете новый сценарий. Если ошибка — прочитайте блок «Если что-то пошло не так» внизу.

Ссылка на n8n Cloud: https://app.n8n.cloud

1 Зарегистрироваться в n8n Cloud
Зайдите на app.n8n.cloud → Sign Up / Get Started
Зарегистрируйтесь через email + пароль (или Google/GitHub — быстрее)
Подтвердите email (придёт письмо)
Выберите тариф: Starter — 14 дней бесплатно, карту вводить не нужно
Дождитесь открытия рабочей области (n8n editor)
✅ Результат: вы в редакторе n8n, видите пустой холст (Canvas)
2 Создать первый workflow
Нажмите Add Workflow (или «+» в левом меню)
Дайте имя: Мониторинг конкурента
Нажмите Save (Ctrl+S / Cmd+S)
✅ Результат: workflow открыт на холсте
3 Импортировать шаблон (Трек А)
Скачайте файл track_a_template.json из раздаток занятия
В редакторе n8n нажмите Import Workflow (кнопка с облачком в левом меню)
Выберите скачанный файл → Open
На холсте появились 10 нод (квадратиков, соединённых линиями)
Нажмите Save
✅ Результат: цепочка Старт → Пост-донор → Фильтр → LLM → Строка → Таблица
4 Подключить LLM (ключ от тренера)
Кликните на ноду «🤖 Саммаризация (LLM)»
Найдите поле Credential for HTTP Request → Create New
Тип: Header Auth
Заполните:
• Name: LLM API (мой OpenRouter/AiTunnel)
• Header Name: Authorization
• Header Value: Bearer sk-or-... (ваш API-ключ)
Нажмите Save
✅ Результат: LLM подключена
5 Подключить Google Sheets (свой аккаунт)
Кликните на ноду «📝 Лента заметок (Sheets)»
Credential for Google Sheets → Create New → Google Sheets OAuth2 API
Нажмите Sign In with Google → выберите свой аккаунт → разрешите доступ
✅ Результат: Google Sheets подключен (один раз — работает навсегда)
6 Заменить 3 значения
🔴 Канал-донор: нода «📄 Пост-донор» → поле channel → впишите название канала конкурента
🔴 Ключевые слова: нода «🔍 Фильтр» → замените слова под свою тему (транспорт, ЖКХ, происшествия)
🔴 Таблица: нода «📝 Лента заметок» → documentId → вставьте ID своей Google Таблицы
Поле sheetName: обычно оставить «Лист1»
Нажмите Save
✅ Результат: 3 значения заменены, workflow настроен под ваш кейс
7 Запустить (Execute)
Сохраните workflow (Ctrl+S / Cmd+S)
Нажмите Execute Workflow — кнопка с треугольником на ноде «▶ Старт»
Наблюдайте: ноды загораются зелёным по цепочке
Проверьте Google Таблицу — там появилась строка: дата | канал | тема | саммари | ссылка
✅ Результат: первый сценарий запущен!
8 Активировать (чтобы работало само)
В правом верхнем углу найдите переключатель Inactive / Active
Переведите в Active
Workflow работает по расписанию (Schedule) или событию (Trigger)
Важно: на занятии не активируем — тестируем через Execute. Активируйте дома, когда настроите реальный триггер (Schedule / Telegram Trigger).
✅ Результат: workflow работает в фоновом режиме

Если что-то пошло не так

ПроблемаЧто делать
Execute не даёт строку в таблицеПроверьте ветку IF — возможно, ни одно ключевое слово не совпало. Нажмите на ноду IF → посмотрите, на какую ветку ушёл запрос (true или false)
Ошибка 401/403 в узле LLMНеверный API-ключ или не выбран credential. Откройте ноду «🤖 Саммаризация» → проверьте, что credential выбран и указан верный ключ
Ошибка в Google SheetsНеверный documentId или нет доступа к таблице. Проверьте, открыта ли таблица для вашего Google-аккаунта
Фильтр пропускает всёУдалите все условия в ноде IF, кроме одного — проверьте работу, потом добавляйте остальные
Не видно нод на холстеПрокрутите холст вправо (полоса внизу); все ноды расположены горизонтально
Кнопка Import неактивнаУбедитесь, что workflow открыт на холсте, а не в списке. Нажмите Add Workflow → переименуйте → Save → теперь импорт активен
Работает медленноБесплатный n8n Cloud имеет ограничения по времени. Для теста достаточно; для продакшена — свой сервер

Что дальше

После успешного запуска переходите к Домашнему заданию:

  1. Выберите 1 повторяющийся процесс из своих обязанностей
  2. Опишите по шаблону: цель → источник → действие → куда сохранять
  3. Соберите черновик в n8n (по этому чек-листу) или в LobeHub
  4. Замерьте время: вручную vs с ИИ
  5. Принесите на Занятие 2

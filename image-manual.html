Картинка за 5 минут: генерация и редактирование

v1.0 · 23.09.2026 · Курс ИИ-инструменты для региональной редакции
На втором занятии мы не успели дойти до визуала. Этот документ закрывает пробел: от промпта и генерации — до редактирования и чек-листа «можно ли это публиковать».

1. Что вы сможете после этого мануала

  • Сделать иллюстрацию к посту за 5 минут
  • Сгенерировать обложку статьи, афишу события, фон под цитату
  • Отредактировать готовую картинку: убрать лишний объект, расширить кадр, подогнать под формат площадки
  • Понимать, когда ИИ-картинку публиковать нельзя

4. Формула промпта

Объект → Действие → Окружение → Стиль → Цвета → Формат → ЗАПРЕТЫ

Шаблон, который можно копировать:

[Объект: что/кто], [что делает], [окружение: где, время суток, погода].
Стиль: [фотореализм / иллюстрация / инфографика / акварель].
Цвета: [фирменные цвета редакции].
Формат: [16:9 горизонтальный / 1:1 / 9:16].
Запреты: без людей, без лиц, без логотипов, без торговых марок, без текста, без водяных знаков.

Разбор на примере

Парк в центре города, осенний пейзаж, золотые листья, скамейки, утренний свет. Стиль: фотореализм. Цвета: тёплый оранжевый, приглушённый зелёный. Формат: 16:9. Запреты: без людей, без лиц, без логотипов, без текста.
Чем конкретнее объект, время суток и свет — тем лучше результат. «Красивый город» даст случайную картинку, «старая водонапорная башня на закате, силуэт» — почти всегда нужную.

5. Обязательные ЗАПРЕТЫ

Копируйте этот блок в каждый промпт:

без людей, без лиц, без логотипов, без торговых марок, без текста, без водяных знаков, без государственной символики

Почему это критично:

  • Люди и лица — риск «фейкового фотофакта», портретного сходства, лишних вопросов
  • Логотипы и торговые марки — риск претензий правообладателя
  • Государственная символика — можно получить искажённый флаг/герб, что недопустимо в публикации
  • Текст — ИИ рисует буквы с ошибками

6. Пять готовых промптов под редакционные задачи

1. Городской пейзаж (рубрика «Наш город»)
Центральная площадь провинциального города вечером, фонари, мокрая брусчатка после дождя, силуэты зданий на фоне заката. Стиль: фотореализм. Цвета: тёплый янтарный, тёмно-синий. Формат: 16:9. Запреты: без людей, без лиц, без логотипов, без текста.
2. Дорожные работы (городская повестка)
Участок городской дороги с ремонтом: свежий асфальт, дорожные конусы, красно-белая лента, техника без опознавательных знаков. Стиль: репортажное фото. Цвета: серый, оранжевый. Формат: 16:9. Запреты: без людей, без лиц, без логотипов, без торговых марок, без текста.
3. Осенняя рубрика
Осенний двор жилого дома, клёны, ковёр из опавших листьев, скамейка, детская площадка без детей. Стиль: мягкая иллюстрация. Цвета: золотой, кирпично-красный. Формат: 1:1. Запреты: без людей, без лиц, без логотипов, без текста.
4. Афиша события (фон без текста)
Сцена в небольшом городском ДК перед концертом, приглушённый свет, микрофон, пустой зал на заднем плане. Стиль: кинематографичный фотореализм. Цвета: глубокий бордовый, тёплый бежевый. Формат: 9:16. Запреты: без людей, без лиц, без логотипов, без текста, без водяных знаков.
5. Фон под цитату
Абстрактный фон: мягкие волны тумана над рекой на рассвете. Стиль: минимализм. Цвета: приглушённый зелёный и тёплый бежевый. Формат: 9:16. Запреты: без людей, без текста, без логотипов.

7. Пошагово: Kandinsky / FusionBrain

  1. Зайдите на fusionbrain.ai, войдите через SberID / GigaChat
  2. Выберите соотношение сторон: 16:9 (широкий), 1:1 (квадрат), 9:16 (вертикаль для сторис)
  3. Вставьте промпт, добавьте негативный промпт (тот же блок запретов)
  4. Сгенерируйте, посмотрите варианты
  5. Скачайте файл без водяного знака (если тариф даёт) или сделайте скриншот без интерфейса
  6. Доработайте (см. раздел 8)
Шедеврум устроен проще: вводите промпт в приложении, получаете 4 варианта, выбираете лучший. Для быстрых картинок «на бегу» — самое удобное.

8. Редактирование

ЗадачаДействиеПромпт
Убрать лишний объектInpaint → выделить объект«Убрать, оставить только фон»
Заменить объектInpaint → выделить область«Заменить на скамейку у пруда»
Дотянуть форматOutpaint → расширить холст«Продолжить небо и дорогу»
Увеличить разрешениеUpscale / «Улучшить»—
Inpaint — это «забота редактора»: даже одна перегенерированная область часто спасает картинку.

9. Текст и логотип — только руками

  • Заголовки и подписи накладывайте в Canva / Photoshop / Figma / любом редакторе. ИИ почти гарантированно ошибётся в буквах
  • Фирменный логотип не просите нарисовать — вставляйте файл поверх картинки
  • Фирменные цвета в промпте задавайте словами («приглушённый зелёный и тёплый бежевый»), а точный цвет — заливкой в редакторе. Это даёт единство рубрики

10. Чек-лист перед публикацией

Нет лиц (или есть согласие / это не реальный человек)
Нет логотипов и торговых марок
Нет государственной символики
Нет искажённого текста
Нет водяных знаков
Картинка не выглядит как реальный фотофакт события (иначе — пометка «иллюстрация»)
Проверены метаданные файла (EXIF)
Есть пометка о генерации ИИ, если это уместно

11. Право, этика и маркировка

  • Маркировка ИИ-контента. 26.07.2026 подписан ФЗ № 243-ФЗ об ИИ. Механизм маркировки вводится с 1 марта 2027. Автор маркирует контент добровольно, а площадки с аудиторией более 500 тыс. пользователей обязаны дать техническую возможность поставить пометку
  • Практика сейчас: в подписи указывайте «Иллюстрация сгенерирована ИИ» — это снимает вопросы и у читателей, и у редакции
  • Не используйте промпты «в стиле художника X» и не воспроизводите чужие работы — риск авторских претензий
  • Коммерческое использование. Kandinsky/FusionBrain разрешает при соблюдении правил сервиса; у каждого сервиса свои условия — читайте перед размещением рекламы
  • Не генерируйте реалистичные изображения узнаваемых людей и событий, которых не было (дипфейк-риски — главный красный флаг в новостных редакциях)
  • Метаданные. EXIF сгенерированных файлов может содержать данные сервиса. Проверьте файл через exifdata.com или «Свойства файла» перед публикацией

12. Типичные ошибки и что делать

ПроблемаРешение
Кривые руки/лицаВ промпт — «без людей»; либо inpaint-перегенерация
Абракадабра вместо текстаУбрать текст из промпта, накладывать руками
«Выглядит слишком ИИшно»Добавить стиль, свет, ракурс, реальные детали места
Мусор в деталяхАпскейл + inpaint или перегенерация
Водяной знакПлатный тариф или другой сервис
Все картинки одинаковыеМенять ракурс, время суток, стиль; добавлять 2–3 детали темы

13. Чек-лист и ДЗ на месяц

Чек-лист навыка:

Сгенерирована 1+ картинка в Kandinsky / Шедевруме
Промпт построен по формуле и содержит запреты
Сделана правка через inpaint или outpaint
Проверена EXIF и чек-лист перед публикацией
ДЗ: сделайте 5 иллюстраций по бренд-буку — по одной на каждую рубрику редакции. Сдайте в чат курса.

Вопросы — в чат курса. Если картинка вышла неудачной — перегенерируйте, добавив конкретики про место и свет: обычно с третьей попытки получается рабочая иллюстрация.
